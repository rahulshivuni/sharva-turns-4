# Superhero Birthday RSVP

A comic-book RSVP page for the 4th birthday bash. Friends open the GitHub Pages link, send YES / NO, and their full name shows on the attending heroes list.

## Before you share the link

1. Open `config.js` and add the party date, time, and location.
2. Create a free pantry at [getpantry.cloud](https://getpantry.cloud) with your email, then paste the pantry ID into `config.js`. That is what lets every friend share one guest list.
3. Confirm the first RSVP email from [FormSubmit](https://formsubmit.co) so new replies also land in your inbox.

## Put it on GitHub Pages

1. Create a GitHub repo and upload this folder.
2. In the repo: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
3. Share the Pages URL, for example `https://YOUR-USERNAME.github.io/superhero-birthday/`.

FormSubmit emails RSVPs to the host address in `config.js`. Guests enter first and last name.
